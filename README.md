Project: Infusion Delivery Company Landing Page
Purpose: Technical Test for UI/UX Developer Role at Linkit360

Overview
This project is a responsive landing page designed for an infusion delivery company, developed as part of the technical assessment for the UI/UX Developer position at Linkit360. The goal was to create a clean, user-friendly interface that effectively communicates the company’s services while ensuring an optimal user experience.

Key Features
✅ Modern & Professional Design – A sleek, visually appealing layout tailored for healthcare professionals and patients.
✅ Fully Responsive – Seamless experience across desktop, tablet, and mobile devices.
✅ Built with Tailwind CSS – Utilized for rapid, utility-first styling with maintainable and scalable code.
✅ User-Centric UX – Intuitive navigation, clear CTAs, and structured content for easy information access.
